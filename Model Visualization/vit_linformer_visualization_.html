Figure 1: Vision Transformer with Linformer Architecture
Architecture overview of the proposed Vision Transformer with Linformer optimization. The input image (224×224×3) is divided into non-overlapping patches of size 32×32, resulting in 49 patches. Each patch is linearly embedded into a 128-dimensional vector and concatenated with a learnable classification token (CLS). The sequence is processed through 12 Transformer blocks utilizing Linformer attention mechanism with k=64 for linear complexity. Each block contains 8 attention heads with 20% dropout. The final classification is performed using the CLS token representation.
