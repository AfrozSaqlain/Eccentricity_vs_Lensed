Figure 3: Convolutional Neural Network Architecture
Architecture of the proposed CNN model for 3-class classification. The network consists of three convolutional blocks, each containing a 3×3 convolution layer followed by ReLU activation and 2×2 max pooling. The feature maps progressively increase in depth (32→64→128 channels) while spatial dimensions are reduced through pooling operations. After flattening, two fully connected layers perform classification with dropout (p=0.5) for regularization. The input image size is assumed to be 224×224×3, resulting in 28×28×128 feature maps before flattening.
