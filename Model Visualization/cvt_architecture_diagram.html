Figure 2: Convolutional Vision Transformer (CvT) Architecture
Multi-stage CvT architecture with convolutional embeddings and hierarchical feature learning. The model consists of three stages with progressively increasing embedding dimensions (64→192→384) and attention heads (1→3→4). Each stage uses convolutional embeddings for spatial down-sampling and feature extraction, followed by transformer blocks with convolutional projections for key-value pairs. Stage 1 uses 7×7 conv with stride 4, while stages 2 and 3 use 3×3 conv with stride 2. The depth increases significantly in stage 3 (10 blocks) for fine-grained feature learning. Final classification uses global average pooling.
